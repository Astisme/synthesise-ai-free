# Validation workflow

1. Write customer, problem, solution and payment hypotheses.
2. Rank assumptions by impact and uncertainty.
3. Select the smallest experiment that can falsify the riskiest assumption.
4. Predefine segment, recruitment, method, sample, timeframe, cost and thresholds.
5. Run the experiment and preserve raw observations with consent.
6. Separate observations from interpretation; note bias and limitations.
7. Decide proceed, iterate, pivot or stop.
8. Update the hypothesis register and portable project brief.

A proposed experiment is not validation. A small sample informs a decision but does not automatically represent an entire market.
