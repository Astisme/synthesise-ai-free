# Contributing

Thank you for improving Synthesise AI Free.

## Principles
- Keep skills/synthesise-ai-free/ as the single canonical implementation.
- Prefer evidence-led, reproducible methods over prompt accumulation.
- Label hypotheses, fictional examples and uncertain claims.
- Never add fabricated market data, testimonials or success claims.
- Keep supporting material concise and use progressive disclosure.

## Changes
1. Open an issue describing the problem or proposed improvement.
2. Make changes in the canonical skill, reference, workflow or template.
3. Run python scripts/validate.py.
4. Update CHANGELOG.md for user-visible changes.
5. Include examples or tests for new scoring, workflow or validation behaviour.

## Pull requests
Explain the user problem, approach, compatibility impact and validation performed. Avoid harness-specific forks unless technically required; prefer installation documentation or thin adapters.
