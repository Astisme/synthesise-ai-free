# FAQ

## Is this the official Synthesise AI product?
No. It is an independent MIT-licensed project inspired by publicly described product-development concepts. It is not affiliated with or endorsed by Synthesise AI.

## Does a high UVZ score prove demand?
No. Scores prioritize hypotheses. Demand requires customer evidence and appropriately designed experiments.

## Does it browse the market automatically?
Only when the host agent has suitable research tools and permission. Otherwise it identifies evidence gaps and provides a research plan.

## Can I start in the middle?
Yes. Ask for market research, a product charter, curriculum, pricing or launch planning directly.

## How is project context preserved?
Save and update PROJECT-BRIEF.md in your project. Bring it into any compatible agent to continue.

## Why does an agent not load the skill?
Confirm the complete skill directory is installed in a supported location, the harness supports Agent Skills, and the session has been reloaded. Keep reference folders adjacent to SKILL.md.

## Can I use it commercially?
The repository is MIT licensed. Review LICENSE and any third-party materials you add. The skill does not provide legal, tax or financial advice.
